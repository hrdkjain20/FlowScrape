FlowScrape privacy & threat model

FlowScrape performs capture locally after you explicitly activate it. Optional AI cleanup is separately user-initiated and clearly identifies what is sent.

Local capture

  • Captured records stay in extension-owned IndexedDB unless you deliberately export them.
  • Settings and lightweight recovery metadata use chrome.storage.local.
  • FlowScrape has no analytics, remote scripts, cookie access, or page-localStorage writes.
  • Exports are initiated by you and written through Chrome's download UI or clipboard.

Optional Groq AI cleanup

  • AI cleanup is off by default and runs only when you choose Clean with AI.
  • Groq receives field names, types, coverage/uniqueness statistics, up to three shortened sample values per visible field, and your optional cleanup instruction. FlowScrape does not place the complete record dataset or API key inside the AI prompt.
  • Your Groq API key is sent to api.groq.com only as an authorization header. Session-only storage is the default. Persistent extension-local storage is an explicit option; browser extension storage is not a hardware-backed secret vault.
  • Original IndexedDB records remain unchanged. The AI-cleaned result is a separate preview, and exports clearly identify whether the original or cleaned view is selected.
  • Data sent to Groq is handled under Groq's terms and privacy practices. Do not use AI cleanup for data you are not authorized to send to that provider.

Permission boundaries

Required permissions are limited to activeTab, scripting, storage, sidePanel, and downloads. Access to https://api.groq.com/* is optional and requested only when you configure or use Groq. No broad installation-time website permission is required.

Extension compromise through remote codeAll executable code is bundled; manifest CSP permits no remote scripts or eval. Groq returns data only.

Your responsibility

Only collect and transmit information you are authorized to access. FlowScrape does not bypass CAPTCHAs, authentication, paywalls, rate limits, access controls, or anti-bot systems.
